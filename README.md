# OSINT public-search bot\n\nMinimal Telegram bot that creates search links for publicly indexed web pages. It does not access private profiles, leaked databases, or hidden personal data.\n\nRailway variables:\n- `BOT_TOKEN`: token from @BotFather\n- `ADMIN_IDS`: your numeric Telegram ID; comma-separated for multiple owners\n- `ACCESS_IDS`: optional comma-separated IDs initially allowed\n- `DB_PATH`: optional database path, default `osint_bot.db`\n\nThe owner can add/remove users through the bot menu. To keep the SQLite database across redeploys, attach a Railway Volume and set `DB_PATH` to a path inside it, such as `/data/osint_bot.db`.\n\nDeploy from phone: upload these files to the repository root, deploy that repository on Railway, set variables, redeploy, then send `/start` to the bot. Send `/id` to see your Telegram ID.\n
